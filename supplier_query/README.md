# 供应商不良行为自动查询与归档工具

## 一、项目简介

本工具是一款跨平台的供应商不良行为自动查询与归档系统，支持 Windows 10/11、统信UOS、银河麒麟、中标麒麟等操作系统。

### 核心功能

- 自动查询供应商在多个政府网站的不良行为记录
- 支持工程类供应商的特殊监管平台查询
- 自动截取查询结果页面
- 生成标准化的 Word 格式查询报告
- 全中文界面，操作简便

## 二、查询站点

### 通用站点（所有供应商必查）

1. 中国裁判文书网
2. 信用中国
3. 中国政府采购网
4. 国家企业信用信息公示系统
5. 烟草行业采购管理信息系统

### 工程类专属站点（仅工程类供应商）

6. 全国建筑市场监管公共服务平台
7. 广东省建筑市场监管公共服务平台

## 三、环境搭建

### Windows 系统

1. 安装 Python 3.8+
   - 下载地址: https://www.python.org/downloads/

2. 双击运行 `start_windows.bat`

3. 首次运行会自动安装依赖和浏览器

### 统信UOS / 银河麒麟 / 中标麒麟

1. 安装 Python 3 和 pip
   ```bash
   sudo apt-get install python3 python3-pip
   ```

2. 运行安装脚本
   ```bash
   chmod +x install_deps.sh
   ./install_deps.sh
   ```

3. 启动应用
   ```bash
   chmod +x start_linux.sh
   ./start_linux.sh
   ```

## 四、账号配置

### 默认账号

- 用户名: `admin`
- 密码: `admin123`

### 修改默认密码

首次登录后，可选择"记住密码"功能，密码将以加密形式存储在本地。

## 五、操作步骤

1. **登录**
   - 输入用户名和密码
   - 可勾选"记住密码"方便下次登录
   - 点击"登录"按钮

2. **录入查询信息**
   - 供应商名称
   - 统一社会信用代码
   - 选择是否工程类供应商
   - 选择文件存储目录

3. **开始查询**
   - 点击"开始查询"按钮
   - 程序将自动打开浏览器并逐一访问各站点
   - 每个站点加载完成后自动截图

4. **查看结果**
   - 查询完成后自动生成 Word 报告
   - 输出目录将自动打开
   - 文件夹包含所有截图和报告文档

## 六、文件归档

### 目录结构

```
{供应商名称}_YYYYMMDD_HHMM/
├── 中国裁判文书网_供应商名_时间戳.png
├── 信用中国_供应商名_时间戳.png
├── ...
├── 供应商不良行为查询报告_供应商名_时间戳.docx
```

### 命名规则

- **文件夹**: `{供应商名称}_YYYYMMDD_HHMM`
- **截图**: `{网站名称}_{供应商名称}_{时间戳}.png`
- **报告**: `供应商不良行为查询报告_{供应商名称}_{查询时间}.docx`

## 七、Word报告格式

报告包含以下内容：

1. 报告标题
2. 基本信息表（供应商名称、信用代码、是否工程类、查询时间）
3. 各站点查询结果截图（按查询顺序）
4. 查询统计（成功/失败站点数）
5. 失败站点说明（如有）

## 八、系统要求

### 最低配置

- CPU: 双核 1.5GHz
- 内存: 4GB
- 硬盘: 500MB 可用空间
- 显示器: 1024x768 分辨率

### 软件依赖

- Python 3.8+
- Tkinter (python3-tk)
- Chromium 或 Firefox 浏览器

## 九、注意事项

1. **网络要求**: 查询过程需要稳定的互联网连接
2. **防爬虫**: 各站点有防爬虫机制，程序已内置延时策略
3. **验证码**: 如遇验证码，程序会暂停等待人工处理
4. **并发限制**: 不建议同时运行多个查询任务
5. **存储空间**: 大量查询会占用较多磁盘空间，定期清理历史记录
